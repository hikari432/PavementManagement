# 開発中のエラーと解決記録

## 1. Spring Security導入後にアプリケーションが起動しない

### 発生した問題

Spring Securityでログイン機能を実装する際、ユーザーのパスワードを環境変数から取得する仕組みに変更したところ、アプリケーションが正常に起動しなくなった。

### 原因

`SecurityConfig.java` では、以下の環境変数からログイン用パスワードを取得する設計にしていた。

- `PAVEMENT_ADMIN_PASSWORD`
- `PAVEMENT_USER_PASSWORD`

しかし、Eclipseの実行構成に環境変数を設定していなかったため、パスワードを取得できず、起動処理でエラーが発生していた。

### 対処方法

1. Eclipseのコンソールで起動時のエラーを確認した。
2. `SecurityConfig.java` の環境変数を取得する処理を確認した。
3. Eclipseの「実行構成」からSpring Bootアプリケーションの設定を開いた。
4. 「環境」タブに必要な2つの環境変数を登録した。
5. アプリケーションを再起動し、ログイン画面から正常にログインできることを確認した。

### 学んだこと

- 環境変数を使用する場合、プログラム側の実装だけでなく、実行環境にも設定が必要であること。
- エラー発生時には、コンソールの内容と関連するソースコードを照らし合わせて原因を調査すること。
- パスワードをソースコードに直接記述せず、環境変数で管理する方法を学んだ。
