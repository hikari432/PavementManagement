# 機能一覧表

## 舗装会社 業務管理システム（PavementManagement）

本システムは、舗装会社の工事情報、売上、経費を一元管理し、収支状況を把握するためのWebアプリケーションです。

## 実装機能

| No. | 機能分類 | 機能名 | 概要 |
| --- | --- | --- | --- |
| 1 | 認証 | ログイン | 管理者・一般ユーザーのアカウントでログインする |
| 2 | 認証 | ログアウト | ログイン状態を終了する |
| 3 | 権限管理 | 操作権限の制御 | 管理者と一般ユーザーの権限を区別し、登録・編集・削除の操作を制限する |
| 4 | 権限管理 | アクセス拒否画面 | 権限のない画面へのアクセス時に案内を表示する |
| 5 | ダッシュボード | 業務状況の集計表示 | 工事件数、売上合計、経費合計、利益、未入金額を表示する |
| 6 | 工事管理 | 工事一覧 | 登録された工事情報を一覧表示する |
| 7 | 工事管理 | 工事登録 | 工事名、発注者、工期、状態を登録する |
| 8 | 工事管理 | 工事編集 | 登録済みの工事情報を変更する |
| 9 | 工事管理 | 工事削除 | 登録済みの工事情報を削除する |
| 10 | 売上管理 | 売上一覧 | 売上情報を一覧表示する |
| 11 | 売上管理 | 売上登録 | 売上名、関連工事、金額、売上日、入金状況を登録する |
| 12 | 売上管理 | 売上編集 | 登録済みの売上情報を変更する |
| 13 | 売上管理 | 売上削除 | 登録済みの売上情報を削除する |
| 14 | 経費管理 | 経費一覧 | 経費情報を一覧表示する |
| 15 | 経費管理 | 経費登録 | 経費名、関連工事、金額、支払日、経費区分を登録する |
| 16 | 経費管理 | 経費編集 | 登録済みの経費情報を変更する |
| 17 | 経費管理 | 経費削除 | 登録済みの経費情報を削除する |
| 18 | 収支管理 | 利益表示 | 売上合計から経費合計を差し引いた利益を表示する |
| 19 | 収支管理 | 工事別利益表示 | 工事に紐づく売上・経費を基に工事別の収支を表示する |
| 20 | 入力チェック | 入力値の検証 | 必須項目や金額の下限などを検証する |

## 権限の概要

| 操作 | 管理者（ADMIN） | 一般ユーザー（USER） |
| --- | :---: | :---: |
| ダッシュボードの閲覧 | ○ | ○ |
| 工事・売上・経費の一覧閲覧 | ○ | ○ |
| 工事・売上・経費の登録・編集・削除 | ○ | × |
| 利益・工事別利益の閲覧 | ○ | ○ |

※ 権限制御の一覧はアプリの設計意図をまとめたものです。実際のURLごとのアクセス制御は `SecurityConfig.java` と各Controllerのマッピングで確認してください。

## 使用技術

- Java / Spring Boot
- Spring MVC / Spring Data JPA / Spring Security
- Thymeleaf
- H2 Database
- Maven
